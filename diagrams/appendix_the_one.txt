ภาคผนวก ก
การติดตั้งเครื่องมือที่ใช้พัฒนาโปรแกรม

    การติดตั้งเครื่องมือที่ใช้ในการพัฒนาเว็บแอพพลิเคชันระบบจองคิวซ่อมรถจักรยานยนต์และ AI Chatbot ให้คำปรึกษา (THE_ONE) มีโปรแกรมและเครื่องมือที่จำเป็นในการพัฒนาระบบ ดังต่อไปนี้

ก.1 การติดตั้ง Visual Studio Code (VS Code)

    Visual Studio Code เป็น Code Editor ยอดนิยมจาก Microsoft ใช้สำหรับเขียนโปรแกรมและแก้ไขซอร์สโค้ด รองรับภาษาโปรแกรมหลากหลาย และมี Extension ช่วยเสริมประสิทธิภาพมากมาย

    ขั้นตอนการติดตั้ง:
    1) เปิดเว็บเบราว์เซอร์ เข้าเว็บไซต์ https://code.visualstudio.com/
    2) กดปุ่ม "Download for Windows" (หรือ macOS/Linux ตามระบบปฏิบัติการที่ใช้)
    3) เปิดไฟล์ที่ดาวน์โหลดมา (VSCodeSetup-x64-x.x.x.exe) แล้วทำตามขั้นตอนการติดตั้ง
    4) ในหน้า "Select Additional Tasks" แนะนำให้ติ๊กเลือก:
       - "Add to PATH" เพื่อให้เปิด VS Code จาก Terminal ได้
       - "Add 'Open with Code' action to Windows Explorer file context menu"
    5) กด Install และรอจนเสร็จสิ้น
    
    Extension ที่แนะนำให้ติดตั้งเพิ่มเติม:
    - Python (ms-python.python) - สำหรับเขียนโค้ด Python
    - Pylance (ms-python.vscode-pylance) - สำหรับ IntelliSense ภาษา Python
    - Docker (ms-azuretools.vscode-docker) - สำหรับจัดการ Docker Container
    - Django (batisteo.vscode-django) - สำหรับ Syntax Highlighting ของ Django Template
    - Tailwind CSS IntelliSense (bradlc.vscode-tailwindcss) - สำหรับ Autocomplete คลาส Tailwind

ก.2 การติดตั้ง Python 3.13

    Python เป็นภาษาโปรแกรมที่ใช้ในการพัฒนาระบบหลังบ้าน (Backend) ของโปรเจกต์ ร่วมกับ Django Framework เวอร์ชัน 5.2 โปรเจกต์นี้กำหนดใช้ Python เวอร์ชัน 3.13 ขึ้นไป

    ขั้นตอนการติดตั้ง:
    1) เปิดเว็บเบราว์เซอร์ เข้าเว็บไซต์ https://www.python.org/downloads/
    2) กดปุ่ม "Download Python 3.13.x" (เวอร์ชันล่าสุดในกลุ่ม 3.13)
    3) เปิดไฟล์ที่ดาวน์โหลดมา (python-3.13.x-amd64.exe) จะปรากฏหน้าต่างติดตั้ง
    4) **สำคัญ**: ที่หน้าแรกของตัวติดตั้ง ต้องติ๊กเลือก "Add Python 3.13 to PATH" 
       เพราะจะทำให้สามารถเรียกใช้คำสั่ง python และ pip ผ่าน Command Prompt หรือ Terminal ได้
    5) เลือก "Install Now" (ติดตั้งแบบมาตรฐาน) หรือ "Customize installation" (กำหนดเอง)
    6) รอจนติดตั้งเสร็จสิ้น กด Close
    
    การตรวจสอบการติดตั้ง:
    เปิด Command Prompt หรือ PowerShell แล้วพิมพ์คำสั่ง:
    ```
    python --version
    ```
    ถ้าติดตั้งสำเร็จจะแสดงผลลัพธ์เป็น Python 3.13.x

ก.3 การติดตั้ง Docker Desktop

    Docker Desktop ใช้สำหรับจำลองสภาพแวดล้อม Server ในรูปแบบ Container โปรเจกต์ THE_ONE ใช้ Docker Compose ในการรัน Service ต่อไปนี้:
    - PostgreSQL (ankane/pgvector:latest) - ฐานข้อมูลหลักของระบบ รองรับ Vector Search
    - Redis (redis:alpine) - ใช้สำหรับ Caching
    - n8n (n8nio/n8n:latest) - Workflow Automation สำหรับประมวลผล RAG Chatbot
    - Adminer (adminer:latest) - เครื่องมือจัดการฐานข้อมูลผ่าน Web UI
    - ngrok (ngrok/ngrok:latest) - Tunnel สำหรับเปิดให้เข้าถึง Django จากภายนอก

    ขั้นตอนการติดตั้ง:
    1) ต้องเปิดใช้งาน WSL 2 (Windows Subsystem for Linux) ก่อน
       เปิด PowerShell ในฐานะ Administrator แล้วพิมพ์คำสั่ง:
       ```
       wsl --install
       ```
       รีสตาร์ทเครื่องหลังการติดตั้ง WSL เสร็จสิ้น
    2) เปิดเว็บเบราว์เซอร์ เข้าเว็บไซต์ https://www.docker.com/products/docker-desktop/
    3) กดปุ่ม "Download for Windows" แล้วเปิดไฟล์ที่ดาวน์โหลดมา
    4) ทำตามขั้นตอนการติดตั้ง โดยให้ติ๊กเลือก "Use WSL 2 instead of Hyper-V"
    5) รอจนติดตั้งเสร็จสิ้น รีสตาร์ทเครื่องอีกครั้ง
    6) เปิด Docker Desktop ขึ้นมา รอจนสถานะเป็น "Docker is running" (ไอคอนปลาวาฬสีเขียว)
    
    การตรวจสอบการติดตั้ง:
    เปิด Command Prompt หรือ PowerShell แล้วพิมพ์คำสั่ง:
    ```
    docker --version
    docker-compose --version
    ```
    ถ้าติดตั้งสำเร็จจะแสดงเลขเวอร์ชันของทั้ง Docker และ Docker Compose

ก.4 การติดตั้ง Git

    Git เป็นระบบ Version Control ที่ใช้สำหรับจัดการเวอร์ชันของซอร์สโค้ด และใช้ดาวน์โหลดโปรเจกต์จาก GitHub Repository

    ขั้นตอนการติดตั้ง:
    1) เปิดเว็บเบราว์เซอร์ เข้าเว็บไซต์ https://git-scm.com/
    2) กดปุ่ม "Download for Windows" ระบบจะดาวน์โหลดไฟล์ติดตั้งอัตโนมัติ
    3) เปิดไฟล์ที่ดาวน์โหลดมา (Git-x.x.x-64-bit.exe) แล้วทำตามขั้นตอน
    4) ในหน้าเลือก Default Editor แนะนำให้เลือก "Use Visual Studio Code as Git's default editor"
    5) ในหน้า "Adjusting your PATH" เลือก "Git from the command line and also from 3rd-party software"
    6) กด Install และรอจนเสร็จสิ้น
    
    การตรวจสอบการติดตั้ง:
    เปิด Command Prompt หรือ PowerShell แล้วพิมพ์คำสั่ง:
    ```
    git --version
    ```
    ถ้าติดตั้งสำเร็จจะแสดงผลลัพธ์เป็น git version x.x.x

ภาคผนวก ข
คู่มือการติดตั้งระบบ

    คู่มือการติดตั้งระบบ THE_ONE เพื่อใช้งานบนเครื่อง Local Development มีขั้นตอนดังต่อไปนี้

ข.1 ข้อกำหนดเบื้องต้น (Prerequisites)

    ก่อนเริ่มติดตั้งระบบ ต้องมีเครื่องมือดังนี้ติดตั้งอยู่ในเครื่องแล้ว:
    - Python 3.13 ขึ้นไป (ดูวิธีติดตั้งในภาคผนวก ก.2)
    - Docker Desktop (ดูวิธีติดตั้งในภาคผนวก ก.3)
    - Git (ดูวิธีติดตั้งในภาคผนวก ก.4)
    - Google Gemini API Key (สมัครได้ที่ https://aistudio.google.com/apikey)
    - ngrok Authtoken (สมัครได้ที่ https://dashboard.ngrok.com ถ้าต้องการเปิดใช้งาน Tunnel)

    ข้อกำหนดของเครื่อง:
    - ระบบปฏิบัติการ: Windows 10/11 (64-bit), macOS 12+, หรือ Linux (Ubuntu 22.04+)
    - RAM: อย่างน้อย 8 GB (แนะนำ 16 GB เนื่องจาก Docker ใช้ทรัพยากรค่อนข้างสูง)
    - พื้นที่ว่างบนดิสก์: อย่างน้อย 10 GB
    - การเชื่อมต่ออินเทอร์เน็ต (สำหรับดาวน์โหลด Docker Image และ Python Packages)

ข.2 การดาวน์โหลดซอร์สโค้ด

    ดาวน์โหลดซอร์สโค้ดจาก GitHub Repository โดยใช้คำสั่ง Git Clone:
    ```
    git clone https://github.com/zxSUPHASANxz/THE_ONE_FINAL.git
    cd THE_ONE_FINAL
    ```

    หรือสามารถดาวน์โหลดไฟล์ ZIP ได้จาก หน้า GitHub Repository 
    แล้วทำการแตกไฟล์ (Extract) ไว้ในตำแหน่งที่ต้องการ

ข.3 การตั้งค่าไฟล์สภาพแวดล้อม (.env)

    สร้างไฟล์ .env ที่ root directory ของโปรเจกต์ มีรายละเอียดดังนี้:

    ```
    # Django Settings
    DEBUG=True
    SECRET_KEY=your-django-secret-key-change-this

    # Database Configuration (ต้องตรงกับ docker-compose.yml)
    DB_NAME=the_one_db
    DB_USER=suphasan
    DB_PASSWORD=your-database-password
    DB_HOST=localhost
    DB_PORT=5433

    # Google Gemini API (สำหรับ AI Chatbot)
    GEMINI_API_KEY=your-google-gemini-api-key

    # n8n Webhook URL (สำหรับ RAG Chatbot Pipeline)
    N8N_WEBHOOK_URL=http://localhost:5678/webhook/chatbot-rag

    # ngrok (ถ้าต้องการเปิดใช้ Tunnel)
    NGROK_URL=
    NGROK_AUTHTOKEN=your-ngrok-authtoken
    ```

    คำอธิบายแต่ละค่า:
    - SECRET_KEY   : กุญแจลับสำหรับเข้ารหัสข้อมูลของ Django (ต้องเปลี่ยนใน Production)
    - GEMINI_API_KEY: API Key สำหรับเชื่อมต่อ Google Gemini AI 
                      (สมัครฟรีที่ https://aistudio.google.com/apikey)
    - DB_PORT=5433 : พอร์ตของ PostgreSQL ที่ Docker Map ออกมา (ภายใน Container ยังใช้ 5432)
    - N8N_WEBHOOK_URL: URL ของ n8n Webhook ที่ใช้รับข้อความจาก Chatbot

ข.4 การเริ่มต้น Docker Services

    เปิด Docker Desktop ให้ทำงาน (สถานะ "Docker is running") จากนั้นเปิด Terminal 
    ที่ root directory ของโปรเจกต์ แล้วรันคำสั่ง:

    ```
    docker-compose up -d
    ```

    คำสั่งนี้จะดาวน์โหลด Docker Image และสร้าง Container สำหรับ Service ต่อไปนี้:

    | Service  | Container Name   | Port (Host:Container)  | หน้าที่                              |
    |----------|------------------|------------------------|--------------------------------------|
    | postgres | postgres         | 5433:5432              | ฐานข้อมูล PostgreSQL + pgvector      |
    | redis    | (auto)           | 6380:6379              | ระบบ Cache                           |
    | n8n      | THE__ONE_V3      | 5678:5678              | Workflow Automation (RAG)            |
    | adminer  | adminer_the_one  | 8080:8080              | Web UI จัดการฐานข้อมูล              |
    | ngrok    | ngrok_django     | 4040:4040              | Tunnel สำหรับเข้าถึงจากภายนอก      |

    ตรวจสอบสถานะ Container:
    ```
    docker-compose ps
    ```
    ต้องแสดงสถานะ "Up" หรือ "running" ทุก Service

    หมายเหตุ: ครั้งแรกที่รัน อาจใช้เวลานานในการดาวน์โหลด Docker Image (ประมาณ 2-5 นาที 
    ขึ้นอยู่กับความเร็วอินเทอร์เน็ต)

ข.5 การตั้งค่า Python Virtual Environment

    สร้าง Virtual Environment เพื่อแยก Dependencies ของโปรเจกต์ออกจากระบบหลัก:

    สำหรับ Windows:
    ```
    python -m venv .venv
    .venv\Scripts\activate
    ```

    สำหรับ macOS/Linux:
    ```
    python3 -m venv .venv
    source .venv/bin/activate
    ```

    เมื่อ Virtual Environment ถูก Activate สำเร็จ จะเห็น (.venv) ปรากฏหน้า Prompt ใน Terminal

ข.6 การติดตั้ง Python Dependencies

    หลังจาก Activate Virtual Environment แล้ว ติดตั้ง Library ที่จำเป็นทั้งหมด:
    ```
    pip install -e .
    ```
    หรือหากมีไฟล์ requirements.txt:
    ```
    pip install -r requirements.txt
    ```

    Library หลักที่จะถูกติดตั้ง (อ้างอิงจาก pyproject.toml):
    - django >= 5.2.8              : Web Framework
    - djangorestframework >= 3.14.0: REST API Framework
    - djangorestframework-simplejwt : JWT Authentication
    - django-cors-headers          : CORS Management
    - psycopg2-binary              : PostgreSQL Driver
    - google-generativeai          : Google Gemini API Client
    - sentence-transformers        : Text Embedding Model
    - pgvector                     : Vector Database Client
    - beautifulsoup4, selenium     : Web Scraping
    - pillow                       : Image Processing
    - pdfplumber                   : PDF Data Extraction
    - pandas                       : Data Processing

ข.7 การสร้างตารางในฐานข้อมูล (Database Migration)

    ทำการสร้างตารางทั้งหมดในฐานข้อมูล PostgreSQL:
    ```
    python manage.py migrate
    ```

    คำสั่งนี้จะสร้างตารางของทุก Django App ได้แก่:
    - users        : ตารางผู้ใช้ (User, Notification)
    - booking      : ตารางการจอง (Motorcycle, Booking)
    - mechanics    : ตารางงานช่าง (WorkQueue)
    - chat         : ตารางแชท (ChatRoom, Message)
    - chatbot      : ตารางความรู้ AI (KnowledgeBase, ChatHistory)

ข.8 การสร้างบัญชีผู้ดูแลระบบ (Superuser)

    สร้างบัญชี Admin สำหรับเข้าใช้งาน Django Administration:
    ```
    python manage.py createsuperuser
    ```

    ระบบจะถามข้อมูลดังนี้:
    - Username (ชื่อผู้ใช้)    : เช่น admin
    - Email address (อีเมล)  : เช่น admin@theone.com
    - Password (รหัสผ่าน)    : ต้องมีอย่างน้อย 8 ตัวอักษร ไม่ใช่รหัสง่ายเกินไป
    - Password (again)       : ยืนยันรหัสผ่านอีกครั้ง

ข.9 การเริ่มต้น Django Development Server

    รัน Django Development Server:
    ```
    python manage.py runserver
    ```

    เมื่อรันสำเร็จ จะแสดงข้อความ:
    ```
    Starting development server at http://127.0.0.1:8000/
    ```

    เข้าใช้งานระบบผ่าน Web Browser:
    - หน้าแรกของเว็บไซต์      : http://127.0.0.1:8000/
    - หน้า Django Admin       : http://127.0.0.1:8000/admin/
    - หน้า n8n Editor         : http://localhost:5678/
    - หน้า Adminer (DB UI)    : http://localhost:8080/
    - หน้า ngrok Inspector    : http://localhost:4040/

ข.10 การตั้งค่า n8n Workflow (RAG Chatbot)

    n8n ใช้สำหรับประมวลผล RAG (Retrieval-Augmented Generation) Pipeline ของ AI Chatbot
    1) เปิด n8n Editor ผ่าน http://localhost:5678/
    2) สร้างบัญชีผู้ใช้ n8n (ใช้ครั้งแรก)
    3) นำเข้า (Import) Workflow จากไฟล์ในโฟลเดอร์ n8n/workflows/
    4) ตั้งค่า Credentials ใน n8n:
       - PostgreSQL Connection: Host=postgres, Port=5432, DB=the_one_db
       - Google Gemini API Key
    5) เปิดใช้งาน (Activate) Workflow

    คู่มือการใช้งานระบบ THE_ONE แบ่งตามประเภทผู้ใช้งาน 3 ระดับ ได้แก่ สมาชิกทั่วไป (ลูกค้า), ช่างซ่อม (Mechanic) และผู้ดูแลระบบ (Admin)

ค.1 ส่วนการใช้งานทั่วไป

        - โลโก้และชื่อระบบ "THE_ONE" พร้อมคำอธิบาย
        - ปุ่ม "เริ่มคุยกับ Chatbot" สำหรับเข้าสู่หน้า AI Chatbot
        - ปุ่ม "จองคิวซ่อม" (สำหรับลูกค้าที่ Login แล้ว) หรือ "เริ่มใช้งาน (ช่างซ่อม)" (สำหรับช่าง)
        - 3 การ์ดแนะนำฟีเจอร์หลัก: AI Chatbot, จองคิวซ่อม, ทีมช่างมืออาชีพ

        แถบนำทาง (Navigation Bar) ด้านบนประกอบด้วย:
        - เมนู "หน้าหลัก", "Chatbot", "จองคิวซ่อม" (หรือ "ช่างซ่อม" สำหรับช่าง)

        - ไอคอนการแจ้งเตือน (กระดิ่ง) พร้อม Badge แสดงจำนวนแจ้งเตือนใหม่
        - รูปโปรไฟล์ผู้ใช้ พร้อม Dropdown เมนู (โปรไฟล์, การจองของฉัน, ออกจากระบบ)

    ค.1.2 การสมัครสมาชิก (Register)
        URL: http://127.0.0.1:8000/users/register/
        
        ขั้นตอนการสมัครสมาชิก:
        1) กดปุ่ม "สมัครสมาชิก" ที่แถบนำทางด้านบน หรือลิงก์ "สมัครสมาชิกใหม่" ในหน้า Login
        2) กรอกข้อมูลในแบบฟอร์ม:
           - ชื่อผู้ใช้ (Username)     : ต้องไม่ซ้ำกับผู้ใช้คนอื่น
           - อีเมล (Email)            : ใช้สำหรับรับแจ้งเตือนและกู้รหัสผ่าน
           - ชื่อ (First Name)         : ชื่อจริง (ไม่บังคับ)
           - นามสกุล (Last Name)      : นามสกุล (ไม่บังคับ)
           - รหัสผ่าน (Password)      : ต้องมีอย่างน้อย 8 ตัวอักษร
           - ยืนยันรหัสผ่าน (Confirm) : ต้องตรงกับรหัสผ่านที่ตั้ง
           - เบอร์โทรศัพท์             : สำหรับติดต่อ (ไม่บังคับ)
           - รูปโปรไฟล์                : อัปโหลดรูปภาพ (ไม่บังคับ)
        3) กดปุ่ม "สมัครสมาชิก"
        4) หากสำเร็จ ระบบจะพาไปหน้า Login พร้อมแสดงข้อความ "สมัครสมาชิกสำเร็จ"
        5) หากข้อมูลไม่ถูกต้อง ระบบจะแสดง Error เป็นภาษาไทยใต้ช่องที่มีปัญหา

        2) กรอกข้อมูล:
           - ชื่อผู้ใช้ (Username)
           - รหัสผ่าน (Password) - สามารถกดไอคอนรูปตาเพื่อแสดง/ซ่อนรหัสผ่านได้
        3) (ทางเลือก) ติ๊ก "จดจำฉันไว้" เพื่อให้ระบบจำ Session ไว้นานขึ้น
        4) กดปุ่ม "เข้าสู่ระบบ"
        5) หากลืมรหัสผ่าน สามารถกดลิงก์ "ลืมรหัสผ่าน?" เพื่อรีเซ็ตผ่านอีเมล

        - ช่างซ่อม (mechanic): จะถูกนำไปหน้าแรก สามารถเข้าเมนู "ช่างซ่อม" (Dashboard) ได้

        ก่อนทำการจองคิวซ่อม ลูกค้าต้องเพิ่มข้อมูลรถจักรยานยนต์ในระบบก่อน

        การเพิ่มรถใหม่:
        1) เข้าเมนู "จองคิวซ่อม" > กดลิงก์ "คลิกเพื่อเพิ่มรถ" หรือเข้าหน้า "รถจักรยานยนต์ของฉัน"
        2) กรอกข้อมูลในแบบฟอร์ม "เพิ่มรถใหม่":
           - ยี่ห้อ (Brand)                : เช่น Honda, Yamaha, Kawasaki (บังคับกรอก)
           - รุ่น (Model)                  : เช่น CBR1000RR, YZF-R1 (บังคับกรอก)
           - ทะเบียน (License Plate)       : เช่น กข 1234 (บังคับกรอก, ต้องไม่ซ้ำ)
           - ปี (Year)                     : เช่น 2024 (ค่า 1990-2026, บังคับกรอก)
           - ขนาดเครื่องยนต์ (CC)          : เช่น 150, 1000 (ค่า 50-2000, บังคับกรอก)
           - หมายเหตุ (Notes)              : ข้อมูลเพิ่มเติม (ไม่บังคับ)
        3) กดปุ่ม "+ เพิ่มรถ"
        4) เมื่อเพิ่มสำเร็จ รถจะปรากฏในรายการด้านล่าง

        รายการรถที่เพิ่มแล้ว:
        - แสดงเป็นการ์ด โดยมีข้อมูลยี่ห้อ รุ่น ทะเบียน ปี และ CC
        - สามารถลบรถออกจากระบบได้

    ค.2.2 การจองคิวซ่อมรถ (Create Booking)
        URL: http://127.0.0.1:8000/booking/create/
        
        ขั้นตอนการจองคิว:
        1) เข้าเมนู "จองคิวซ่อม" > กดปุ่ม "+ จองใหม่"
        2) กรอกข้อมูลในแบบฟอร์ม:
           - เลือกรถของคุณ (Motorcycle)        : เลือกจาก Dropdown (บังคับ)
             ระบบแสดงรายการรถในรูปแบบ: ยี่ห้อ รุ่น (ทะเบียน)
             ถ้ายังไม่มีรถ จะแสดงลิงก์ "คลิกเพื่อเพิ่มรถ"
           - ประเภทการซ่อม (Service Type)      : เลือกจาก Dropdown (บังคับ)
             ตัวเลือก: ซ่อมบำรุงทั่วไป, ซ่อมเครื่องยนต์, ซ่อมเบรค, 
                       ระบบไฟฟ้า, เปลี่ยนยาง, อื่นๆ
           - อาการหรือรายละเอียด (Description): อธิบายอาการเบื้องต้น (ไม่บังคับ)
           - วันที่ต้องการ (Scheduled Date)    : เลือกวัน (บังคับ, ต้องเป็นวันในอนาคต)
           - เวลาที่ต้องการ (Time Slot)        : เลือกช่วงเวลา
             ตัวเลือก: เช้า (09:00-12:00), บ่าย (13:00-16:00)
           - หมายเหตุเพิ่มเติม (Notes)        : คำขอพิเศษ (ไม่บังคับ)
        3) กดปุ่ม "จองคิว"
        4) ระบบจะตรวจสอบข้อมูล:
           - ตรวจสอบว่ามีการจองซ้ำหรือไม่ (รถคันเดียวกัน + วันเดียวกัน + สถานะ pending)
           - หากซ้ำจะแสดง Error "คุณมีการจองสำหรับรถคันนี้ในวันนี้อยู่แล้ว"
        5) เมื่อจองสำเร็จ สถานะจะเป็น "รอยืนยัน" (pending) และรอช่างมารับงาน

    ค.2.3 การดูรายการจองทั้งหมด (Booking List)
        URL: http://127.0.0.1:8000/booking/
        
        หน้ารายการจองแสดง:
        - ปุ่ม "+ จองใหม่" ที่มุมขวาบน

          * ประเภทการซ่อม
          * วันเวลานัดหมาย
          * สถานะปัจจุบัน (แสดงเป็น Badge สีต่างๆ)
          * ชื่อช่างที่รับผิดชอบ (ถ้ามี)
        - ปุ่ม "ยกเลิกการจอง" (เฉพาะสถานะ pending)
        - ปุ่ม "แชทกับช่าง" (เฉพาะเมื่อมีช่างรับงานแล้ว)

        | สถานะ        | สี    | ความหมาย                                        |

        | pending      | เหลือง| รอช่างมารับงาน                                   |
        | confirmed    | ฟ้า   | ช่างรับงานแล้ว รอดำเนินการ                       |

    ค.2.4 การใช้งาน AI Chatbot
        URL: http://127.0.0.1:8000/chatbot/
        
        AI Chatbot ใช้ Google Gemini API ร่วมกับเทคนิค RAG (Retrieval-Augmented Generation) 
        ผ่าน n8n Workflow เพื่อให้คำปรึกษาเกี่ยวกับรถจักรยานยนต์

        วิธีการใช้งาน:
        1) เข้าเมนู "Chatbot" จากแถบนำทาง
        2) พิมพ์คำถามเกี่ยวกับรถจักรยานยนต์ในช่อง Input ด้านล่าง เช่น:
           - "รถสตาร์ทไม่ติด ควรทำอย่างไร?"
           - "เสียงดังผิดปกติตอนเร่งเครื่อง เกิดจากอะไร?"
           - "ราคาเปลี่ยนยางหน้าประมาณเท่าไร?"
           - "การบำรุงรักษารถตามระยะทำอะไรบ้าง?"
        3) กดปุ่ม "ส่ง" หรือกด Enter
        4) รอ AI ประมวลผล (จะแสดง Animation Typing Indicator ขณะรอ)
        5) AI จะตอบกลับพร้อมข้อมูลที่อ้างอิงจาก Knowledge Base
        
        สิ่งที่ AI ให้คำปรึกษาได้:
        - ปัญหาและอาการผิดปกติของรถ
        - การบำรุงรักษารถตามระยะ
        - คำแนะนำการใช้งาน
        - ราคาและค่าซ่อมโดยประมาณ

        ข้อจำกัดของ AI:
        - ใช้ Google Gemini API ซึ่งมีค่าจำกัด Rate Limit (free tier: 15 requests/นาที)
        - ผลลัพธ์เป็นการประมาณเบื้องต้น ไม่ใช่การวินิจฉัยที่แม่นยำ 100%
        - แนะนำให้นำรถเข้าตรวจกับช่างจริงเสมอ

    ค.2.5 การแชทกับช่าง (Chat)
        URL: http://127.0.0.1:8000/chat/
        
        ระบบแชทจะถูกสร้างขึ้นอัตโนมัติเมื่อช่างรับงาน (Accept Work) 
        ทำให้ลูกค้าและช่างสามารถสื่อสารกันได้โดยตรง

        หน้ารายการแชท (Chat List):
        - แสดงรายการห้องแชททั้งหมด เรียงตามข้อความล่าสุด
        - แต่ละรายการแสดง: ชื่อคู่สนทนา, ข้อความล่าสุด, เวลา, Badge จำนวนข้อความใหม่
        - แสดงข้อมูลรถที่เกี่ยวข้อง (ยี่ห้อ รุ่น + หมายเลขการจอง)

        หน้าห้องแชท (Chat Detail):
        - แสดงข้อความเป็น Bubble (ข้อความตัวเอง = ขวา, คู่สนทนา = ซ้าย)
        - พิมพ์ข้อความในช่อง Input ด้านล่าง แล้วกด "ส่ง"
        - ระบบ Auto-refresh ข้อความใหม่ทุก 2 วินาที (Polling)
        - Badge จำนวนข้อความยังไม่ได้อ่านที่ไอคอนแชทบน Navbar จะอัปเดตอัตโนมัติ

    ค.2.6 การจัดการโปรไฟล์
        URL: http://127.0.0.1:8000/users/profile/
        
        ขั้นตอนการแก้ไขโปรไฟล์:
        1) คลิกที่รูปโปรไฟล์มุมขวาบน > เลือก "โปรไฟล์"
        2) หน้าโปรไฟล์แสดงข้อมูลส่วนตัว:
           - ชื่อผู้ใช้, อีเมล, ชื่อ, นามสกุล, ประเภทผู้ใช้, สถานะบัญชี
           - เบอร์โทรศัพท์, ที่อยู่
        3) กดปุ่ม "แก้ไขข้อมูล" เพื่อเปลี่ยนเป็นโหมดแก้ไข
        4) แก้ไขข้อมูลที่ต้องการ แล้วกด "บันทึก"
        5) สามารถเปลี่ยนรูปโปรไฟล์ได้โดยอัปโหลดรูปภาพใหม่

    ค.2.7 ระบบแจ้งเตือน (Notification)

        ระบบแจ้งเตือนจะส่ง Notification อัตโนมัติเมื่อมี Event สำคัญ:

        การแจ้งเตือนสำหรับลูกค้า:
        | เหตุการณ์                    | ข้อความ                         | ไอคอน |
        |------------------------------|----------------------------------|-------|
        | ช่างรับงาน                   | "มีช่างรับงาน"                   | 👨‍🔧   |
        | การจองได้รับการยืนยัน        | "การจองได้รับการยืนยัน"          | 🎉    |
        | เริ่มดำเนินการซ่อม          | "เริ่มดำเนินการซ่อม"             | 🔧    |
        | งานเสร็จสิ้น                | "งานเสร็จสิ้น"                   | ✅    |
        | การจองถูกยกเลิก             | "การจองถูกยกเลิก"                | ❌    |

        วิธีดูการแจ้งเตือน:
        1) คลิกที่ไอคอนกระดิ่ง (🔔) ที่แถบนำทาง
        2) จะแสดง Dropdown รายการแจ้งเตือน (เรียงตามเวลาล่าสุด)
        3) แจ้งเตือนที่ยังไม่ได้อ่านจะมีจุดสีน้ำเงินกำกับ
        4) คลิกที่แจ้งเตือนเพื่ออ่านและนำไปยังหน้าที่เกี่ยวข้อง
        5) กด "อ่านทั้งหมด" เพื่อ Mark Read ทุกรายการ

        เมื่อมีช่างรับงาน (สำหรับลูกค้า):
        - ระบบจะแสดง Toast Notification พิเศษที่มุมขวาบนของหน้าจอ
        - พร้อมปุ่ม "ดูการจอง" และ "แชทกับช่าง" ให้กดเข้าไปโดยตรง
        - Toast จะหายไปอัตโนมัติหลัง 10 วินาที

ค.3 ส่วนของช่างซ่อม (Mechanic)

    ค.3.1 Mechanic Dashboard
        URL: http://127.0.0.1:8000/mechanics/dashboard/
        
        Dashboard ของช่างแสดง:

        ส่วนหัว (Header):
        - ข้อความ "ยินดีต้อนรับ" พร้อมชื่อช่าง
        - วันที่ปัจจุบัน

        การ์ดสรุปสถิติ (Stats Cards) - แสดง 5 การ์ด:
        | การ์ด         | สีพื้นหลัง    | ความหมาย                      |
        |---------------|---------------|-------------------------------|
        | ⏳ รอรับงาน   | เหลือง-ส้ม   | จำนวนงานที่รอช่างรับ           |
        | ✔️ ยืนยันแล้ว | ฟ้า-สกาย     | จำนวนงานที่ช่างรับแล้ว         |
        | 🔧 กำลังซ่อม  | น้ำเงิน-คราม | จำนวนงานที่กำลังดำเนินการ      |
        | ✅ เสร็จสิ้น   | เขียว-มรกต   | จำนวนงานที่เสร็จแล้ว          |
        | ❌ ยกเลิก      | แดง          | จำนวนงานที่ถูกยกเลิก          |

        แถบ Filter:
        - ปุ่มกรองงานตามสถานะ: ทั้งหมด, รอรับงาน, ยืนยันแล้ว, กำลังซ่อม, เสร็จสิ้น, ยกเลิก

    ค.3.2 การรับงานซ่อม (Accept Work)
        
        ขั้นตอนการรับงาน:
        1) ในหน้า Dashboard ดูรายการงานสถานะ "รอรับงาน" (pending)
        2) แต่ละรายการงานแสดง: ชื่อลูกค้า, ข้อมูลรถ, อาการ, วันนัดหมาย
        3) กดปุ่ม "Accept" (รับงาน) ที่รายการงานที่ต้องการ
        4) ระบบจะแสดง Modal ยืนยัน "คุณต้องการรับงานนี้หรือไม่?"
        5) กด "ยืนยัน"
        6) ระบบจะ:
           - เปลี่ยนสถานะงานเป็น "confirmed" (ยืนยันแล้ว)
           - กำหนดช่างเป็นผู้รับผิดชอบงานนี้ 
           - สร้างห้องแชทระหว่างช่างกับลูกค้า (อัตโนมัติผ่าน Django Signal)
           - ส่ง Notification แจ้งลูกค้าว่า "มีช่างรับงาน"
        
        ข้อจำกัด:
        - งานที่มีสถานะไม่ใช่ "pending" จะไม่สามารถ Accept ได้ (แสดง Error 400)
        - หากช่างอื่นรับงานไปแล้ว จะไม่สามารถ Accept ซ้ำได้

    ค.3.3 การเริ่มซ่อม (Start Repair)
        
        ขั้นตอนการเริ่มซ่อม:
        1) ในหน้า Dashboard กรองงานสถานะ "ยืนยันแล้ว" (confirmed)
        2) กดปุ่ม "Start Repair" (เริ่มซ่อม) ที่รายการงานที่ต้องการ
        3) ระบบจะแสดง Modal ยืนยัน
        4) กด "ยืนยัน"
        5) ระบบจะ:
           - เปลี่ยนสถานะเป็น "in_progress" (กำลังซ่อม)
           - ส่ง Notification แจ้งลูกค้าว่า "เริ่มดำเนินการซ่อม"
        
        ข้อจำกัด:
        - เฉพาะช่างที่เป็นเจ้าของงานเท่านั้น (ตรวจสอบจาก mechanic field)
        - งานต้องอยู่ในสถานะ "confirmed" เท่านั้นจึงจะเริ่มซ่อมได้

    ค.3.4 การแจ้งซ่อมเสร็จ (Complete)
        
        ขั้นตอนการแจ้งซ่อมเสร็จ:
        1) ในหน้า Dashboard กรองงานสถานะ "กำลังซ่อม" (in_progress)
        2) กดปุ่ม "Complete" (เสร็จสิ้น) ที่รายการงานที่ต้องการ
        3) ระบบจะแสดง Modal ยืนยัน
        4) กด "ยืนยัน"
        5) ระบบจะ:
           - เปลี่ยนสถานะเป็น "completed" (เสร็จสิ้น)
           - บันทึกวันที่เสร็จสิ้น (completion_date)
           - ส่ง Notification แจ้งลูกค้าว่า "งานเสร็จสิ้น"
        
        ข้อจำกัด:
        - เฉพาะช่างที่เป็นเจ้าของงานเท่านั้น
        - งานต้องอยู่ในสถานะ "in_progress" เท่านั้นจึงจะแจ้งเสร็จได้

    ค.3.5 การแชทกับลูกค้า

        เมื่อช่างรับงานแล้ว ระบบจะสร้างห้องแชทอัตโนมัติ:
        1) คลิกที่ไอคอนแชท (💬) ที่แถบนำทาง หรือคลิก "แชทกับลูกค้า" ในรายการงาน
        2) พิมพ์ข้อความในช่อง Input เช่น แจ้งรายละเอียดการซ่อม ราคาอะไหล่ ฯลฯ
        3) ข้อความจะส่งถึงลูกค้าแบบ Near Real-time (Polling ทุก 2 วินาที)

    ค.3.6 การแจ้งเตือนสำหรับช่าง

        | เหตุการณ์                     | ข้อความ                          | ไอคอน |
        |-------------------------------|-----------------------------------|-------|
        | มีงานใหม่ (Booking สร้างใหม่) | "มีงานใหม่รอรับ"                  | 🔔    |
        | ลูกค้ายกเลิกงาน              | "ลูกค้ายกเลิกงาน"                | ❌    |

ค.4 ส่วนของผู้ดูแลระบบ (Admin)

    ค.4.1 การเข้าสู่ Django Administration
        URL: http://127.0.0.1:8000/admin/
        
        ใช้บัญชี Superuser ที่สร้างไว้ในขั้นตอน ข.8 เพื่อ Login เข้าสู่ระบบ Admin

    ค.4.2 การจัดการข้อมูลผู้ใช้ (Users)
        
        ในส่วน "USERS" ของ Admin สามารถ:
        - ดูรายการผู้ใช้ทั้งหมดในระบบ
        - เพิ่ม/แก้ไข/ลบ ผู้ใช้
        - เปลี่ยนประเภทผู้ใช้ (customer → mechanic หรือ admin)
          ฟิลด์ user_type มี 3 ค่า: 'customer' (ลูกค้า), 'mechanic' (ช่าง), 'admin' (ผู้ดูแล)
        - รีเซ็ตรหัสผ่านให้ผู้ใช้
        - ดู/จัดการ Notifications ของผู้ใช้แต่ละคน
        
        การตั้งค่าผู้ใช้เป็นช่าง:
        1) เข้าหน้า Admin > Users > เลือกผู้ใช้ที่ต้องการ
        2) เปลี่ยนฟิลด์ "ประเภทผู้ใช้" จาก "ลูกค้า" เป็น "ช่าง"
        3) กด "SAVE"
        4) ผู้ใช้จะสามารถเข้าถึง Mechanic Dashboard ได้ทันที

    ค.4.3 การจัดการข้อมูลการจอง (Bookings)
        
        ในส่วน "BOOKING" ของ Admin สามารถ:
        - ดูรายการจองทั้งหมดในระบบ
        - กรองรายการตามสถานะ, ลูกค้า, ช่างที่รับผิดชอบ, วันที่
        - แก้ไขสถานะการจอง (pending/confirmed/in_progress/completed/cancelled)
        - กำหนดช่างให้กับการจอง
        - ดูรายละเอียดรถจักรยานยนต์ และข้อมูลอาการ
        - จัดการข้อมูลรถ (Motorcycles) ของลูกค้าแต่ละคน

    ค.4.4 การจัดการ Knowledge Base (AI)
        
        ในส่วน "CHATBOT" ของ Admin สามารถ:
        - ดู/เพิ่ม/แก้ไข/ลบ ข้อมูลความรู้ (Knowledge Base)
        - ข้อมูลความรู้ใช้รูปแบบ Vector Embedding สำหรับ RAG
        - ดูประวัติการสนทนา (Chat History) ของ AI Chatbot
        
        การนำเข้าข้อมูลความรู้ใหม่:
        - ใช้ Scripts ในโฟลเดอร์ scraper_and_import_embedding/ เพื่อ Scrape ข้อมูลจากเว็บ
        - หรือนำเข้าจากไฟล์ PDF ผ่าน pdfplumber
        - ข้อมูลจะถูกแปลงเป็น Vector Embedding ด้วย sentence-transformers
        - และจัดเก็บใน PostgreSQL ผ่าน pgvector Extension

    ค.4.5 การจัดการระบบแชท (Chat)
        
        ในส่วน "CHAT" ของ Admin สามารถ:
        - ดูรายการห้องแชท (ChatRoom) ทั้งหมด
        - ดูข้อความ (Message) ในแต่ละห้องแชท
        - ลบห้องแชทหรือข้อความที่ไม่เหมาะสม

    ค.4.6 การจัดการงานช่าง (Mechanics)
        
        ในส่วน "MECHANICS" ของ Admin สามารถ:
        - ดูรายการ WorkQueue ทั้งหมด
        - แก้ไขสถานะงาน
        - กำหนดหรือเปลี่ยนช่างที่รับผิดชอบ

    ค.4.7 การจัดการ Service อื่นๆ

        n8n Workflow Manager:
        URL: http://localhost:5678/
        - ดูและแก้ไข Workflow สำหรับ RAG Chatbot Pipeline
        - ตรวจสอบ Execution History ของ Workflow
        - ตั้งค่า Credentials (PostgreSQL, Gemini API Key)

        Adminer (Database Manager):
        URL: http://localhost:8080/
        - เข้าสู่ระบบด้วย: System=PostgreSQL, Server=postgres, Username=suphasan, 
          Database=the_one_db
        - ดูตารางและข้อมูลในฐานข้อมูลโดยตรง
        - รัน SQL Query ได้

        ngrok Inspector:
        URL: http://localhost:4040/
        - ดู Public URL ที่ ngrok สร้างให้ (สำหรับเข้าถึงระบบจากภายนอก)
        - ตรวจสอบ HTTP Traffic ที่ผ่าน Tunnel
